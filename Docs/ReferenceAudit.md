# Audit des références

Consultation réelle : **5 octobre 2026** (Europe/Paris). Les pages ci-dessous ont été ouvertes pendant cette implémentation. Certaines pages Apple n’exposent qu’un écran JavaScript à l’outil Web : cela est signalé, et ne vaut pas validation du comportement. Les signatures audio/Speech ont également été lues dans les headers et interfaces Swift du SDK iPhoneSimulator 27.0 installé avec Xcode 27.0, build 27A266a, puis vérifiées par `swiftc -typecheck` ciblant iOS 18.

## Complément Vision — 5 octobre 2026

- [VNTrackObjectRequest](https://developer.apple.com/documentation/vision/vntrackobjectrequest) et [VNSequenceRequestHandler](https://developer.apple.com/documentation/vision/vnsequencerequesthandler) : pages ouvertes, signatures compilées SDK27. Le suivi livré mesure une région explicitement choisie, avec seuil de confiance et arrêt ; il n’identifie pas sémantiquement « une personne ».
- [Aligning Similar Images](https://developer.apple.com/documentation/vision/aligning-similar-images), [VNTranslationalImageRegistrationRequest](https://developer.apple.com/documentation/vision/vntranslationalimageregistrationrequest), [alignmentTransform](https://developer.apple.com/documentation/vision/vnimagetranslationalignmentobservation/alignmenttransform) : description officielle/Markdown lus. Le recalage estime la translation entre deux images similaires. La stabilisation du projet utilise cette mesure, un lissage temporel et un recadrage borné ; aucun réglage de session caméra n’est présenté comme traitement d’une vidéo importée. Validité matérielle et résultat du corpus à lire dans le rapport de tests.
